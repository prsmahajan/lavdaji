# Paras Mahajan Portfolio

This repository contains the source code for Paras Mahajan's professional portfolio site. It highlights AI-driven automation, revenue systems, and client offerings built with a modern React + TypeScript stack.

## Tech stack

- Vite + React + TypeScript
- Tailwind CSS and shadcn/ui components
- React Router for client-side routing
- TanStack Query for data fetching and caching

## Getting started

Prerequisites:
- Node.js 18+
- npm

Create a `.env` file (or update your deployment environment) with any required variables:

```
VITE_GTAG_ID=your-google-analytics-measurement-id
```

Install dependencies and start a local dev server:

```sh
npm install
npm run dev
```

The app runs on http://localhost:5173 by default.

## Available scripts

- `npm run dev` – start the local development server
- `npm run build` – create a production build
- `npm run preview` – serve the production build locally
- `npm run lint` – run lint checks

## Deployment

The site is set up for hosting on Vercel. Adjust environment variables or DNS settings as needed for your production domain.
